Assignment 47: Reusable Storage Helper Module

A reusable storage helper provides functions to save, load, remove and clear data from localStorage.

Storage Helper Operations

  • saveData() - stores data.
  • loadData() - retrieves saved data.
  • removeData() - removes selected data.
  • clearData() - clears application data.

    Assignment 50: Project Idea and User Requirements

    Project Title

    Persistent To-Do Application

    Project Idea

    This application helps users organize daily activities, manage their tasks and track their progress. Task information remains saved even after refreshing the browser.

    Core Features

    • Add new tasks.
    • Edit existing tasks.
    • Mark tasks as completed.
    • Delete unwanted tasks.
    • Filter tasks by status.
    • Save tasks using localStorage.
    • Responsive mobile-friendly interface.

    User Requirements

    • The interface should be simple and easy to use.
    • Users should be able to manage tasks quickly.
    • Task data should remain saved after refresh.
    • The application should support mobile screens.
    • Invalid or empty task input should be rejected.

    Technology Requirements

    HTML, CSS, JavaScript and browser localStorage.
